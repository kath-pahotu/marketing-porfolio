# KAThu on marketing

Live: https://kathuonmkt.vercel.app
Repository: https://github.com/kath-pahotu/marketing-porfolio

The portfolio leads with paid acquisition, SEO, conversion and campaign leadership. Seven professional cases come before five independent analytics studies. Business-context sections connect the work through customer journeys and commercial decisions.

## Edit and build

Edit `source/content.py` for case facts, `source/build_site.py` and `source/refine_site.py` for the original presentation, and `source/business_context.py` / `source/business.css` for business context and connections. Run `python build_website.py`. The checked-in website is published directly; Vercel does not run Python.

The homepage business-context selector is generated by `source/business_explorer.py`, with styles and interactions in `source/business-explorer.css` and `source/business-explorer.js`. It covers all 12 cases exactly once across B2B/SaaS (5), retail/marketplaces (3), consumer acquisition (2) and banking/fintech (2). Campaign strategy and delivery lead, followed by conversion and measurement, then independent analytical depth. Company experience supplies context separately. All project links stay visible; native disclosures expose methods, evidence and limits. The Lab delivery and the separate Rokt advertising study are explicitly distinguished. The former Ecosystem/Spotlight/Journey modes have been consolidated. Run `python source/business_explorer.py` to update just this section and its assets without rebuilding other pages.

Edit `source/portrait.css` for the homepage photo framing. The full original image keeps the Artificial Intelligence event lettering visible; the note sits below the portrait on mobile.

The interactive workflow, supporting analytics and capability sections live in `source/section_experiences.py`, `source/section-experiences.css` and `source/section-experiences.js`. Run `python source/section_experiences.py` to update just those three sections on the current homepage. The main build also runs this step. All evidence and case links remain available without JavaScript; controls support keyboard navigation and reduced motion.

The active build is campaign-led. The older `build_tracks.py` and `revamp_content.py` belong to the previous analytics-led version and are not part of this build.

The primary download is `website/documents/Phan_Hoai_Thu_Digital_Marketing_CV.pdf`. The separate Marketing Analyst CV stays available at its existing URL. Power BI is independent-project experience; professional Golden Owl reporting used GA4 and Looker Studio. TrueProfit is excluded.

## Deployment

Pushes to main deploy to the existing kathuonmkt Vercel project. Root: repository root. Framework: Other. Output: website. Keep the root `vercel.json` outputDirectory setting. The separate marketing-porfolio Vercel project also follows this repository.

The confidential case links to the password-protected data portfolio. No private report or access secret belongs in this repository.
